# 既有帳本遷移與公式風險

遷移的第一個產物是檢視報告，不是新帳本。

## 保存原始狀態

- 記錄原始檔名、位置、檔案大小、修改時間與 checksum。
- 不修改或覆蓋原始檔；檢視、轉換與試跑在獨立工作區。
- 列出雲端連結、外部連結、查詢、巨集、加密、保護、隱藏工作表/列/欄、命名範圍、Excel Table、條件格式與資料驗證。

## 不只看畫面顯示值

對電子表格同時檢視：

- 儲存值、公式、公式類型、shared/array/spill 範圍與 cached value。
- 重新計算後的值，特別注意「畫面看似正常，但 cached value 與公式定義不一致」。
- 公式範圍是否固定在舊列數，新增交易會不會被總計、科目餘額、月報或檢查漏掉。
- 公式是否與文字/手動值重疊，計算後可能覆蓋交易欄位。
- 公式錯誤、循環引用、權限/鎖定失效、日期序號/文字混用，以及貨幣/百分比/日期被存為字串。

「借貸檢查 PASS」只是一個控制，不證明公式範圍完整、cached value 可靠、憑證完整或會計政策正確。

## 欄位語意與資料模型

對每個欄位記錄：原名、實際內容、資料型態、符號約定、必填、來源、公式/手動、目標欄位、轉換規則、無法映射值。

不得因為欄名寫「銷貨」就假設內容全是收入；驗證是否混入資本、借款、應收、平台撥款或非交易備忘。

## 調節與上線

1. 產生欄位映射、不可自動映射、資料品質、公式風險、重複/衝突與缺憑證報告。
2. 設定期初餘額與舊系統控制總數，試轉換後逐項調節。
3. 試跑一個完整月結，含銀行、卡片、平台、應收/應付、借貸、open items 與報表。
4. 顯示上線預覽、未解差異、回復方案、架空/唯讀舊系統方式與負責人。
5. 確認後才切換 system of record，並鎖定遷移版本與調節報告。
