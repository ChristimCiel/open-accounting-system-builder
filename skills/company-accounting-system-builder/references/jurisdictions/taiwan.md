# 台灣公司會計與帳務導航

這是導航與查核清單，不是可離線久用的法令結論。每次涉及法令、準則、稅務、門檻、申報與期限，都要重開官方來源，記錄「現行/未來生效、生效日、是否得提前適用、本公司是否選擇提前適用」。

## 決策樹

1. **是否為台灣主體或在台固定營業場所？**
   - 否：不套用本路由，查所在地官方規範。
   - 是：繼續。
2. **是否為以營利為目的公司、商號或其他商業？**
   - 若為財團/社團法人、執行業務者、機關團體或特殊實體，停止套用一般公司模板，查其專屬規範。
3. **是否公開發行、正申請公開發行，或為金融/保險/證券/期貨等特別監理事業？**
   - 是：以金管會或目的事業主管機關專屬財報編製準則導航，不以一般 EAS 模板取代。
   - 否：原則上導航至商業會計法、商業會計處理準則與相關法令；未規定事項再查企業會計準則公報與專業意見。
4. **是否自願比照證券發行人財報編製準則特定條文，或有集團/融資/契約性報導要求？**
   - 記錄適用範圍、版本、轉換日與專業確認；不把有限的「自願比照」宣稱為完整符合 IFRS。
5. **是否達公司法財務報表 CPA 查核門檻，或有銀行/投資人/契約要求？**
   - 即時查核當前門檻。將關帳時程、權限、憑證、調節、調整分錄與 CPA 資料包納入系統。
6. **稅籍、營業稅與發票身分是什麼？**
   - 查稅籍登記、一般/小規模/特種、應稅/免稅/零稅率/兼營、統一發票/電子發票/免用發票與個別核定。不只用單一銷售額數字下結論。
7. **主要產業是什麼？**
   - 買賣業：至少導航日記簿、總分類帳、存貨明細。
   - 製造業：再導航原料、在製品、製成品與生產紀錄。
   - 營建業：再導航在建工程、材料與施工日報。
   - 勞務/其他業：再導航符合實際營運的營運量紀錄。
   - 複合業態：依各主要收入流分別設明細與對帳。

## 台灣必問事實

- 法律型態、設立/開業日、總分支機構、公開發行與特殊許可/監理身分。
- 登記營業項目與實際產品/服務/收入模式，實際營運不能被登記代碼取代。
- 實收資本額、營業收入、勞保員工數、銀行/投資人/集團報導要求、曾否有 CPA 查核/核閱/稅簽。
- 會計年度、記帳本位幣、目前授權的財報架構與是否選擇提前適用新準則。
- 稅籍與國稅局核定身分：發票、電子發票、查定、免稅、零稅率、兼營、網路/平台/跨境銷售。
- 員工、承攬、租金、佣金、利息、權利金、專業報酬、境外給付、關係人、境外股東/關係企業。
- 公司成立前交易、股東代墊/借款/出資、公私帳戶混用、外幣與海外 SaaS/廣告/顧問。

## 版本與生效日風險（歷史驗證快照，禁止直接沿用）

- 以下日期只記錄本 Skill 建立時發現的版本風險，不是執行當下的現行法結論。每次使用都要在 `applicable-framework.md` 另寫 `checked_on`、適用前提與重查觸發條件；未完成即時查核時不得複製本段成為公司結論。
- 2026-08-31 的查核快照中，商業會計處理準則頁面顯示 2026-07-03 修正，部分/全部條文 2028-01-01 施行。不得因網頁已顯示新文就假設當期全部生效；必須讀總說明/對照表與提前適用條款。
- EAS 24「客戶合約之收入」於 2025-09-19 發布，適用於報導期間開始日在 2027-01-01 以後的財務報表，亦得提前適用；實施後 EAS 10「收入」不再適用。收入政策要記錄是否提前適用與轉換方式。
- 金管會證券發行人財報編製準則亦可同時顯示已修正但尚未全部生效條文。公開發行實體不得使用靜態摘要導航。

## 法定帳、稅務與管理帳的關係

保持單一、依真實事項記載的複式總帳，再導出法定財報、稅務調整與管理分析。營利事業所得稅的差異在申報中調整，不應回頭竄改事實帳。

## 必須升級的台灣情境

公司成立前交易、股本/股東/關係人、稅額/扣繳/可扣抵、預收/收入認列/跨期、平台主理人-代理人與總額-淨額、退款/折讓/反佣、境外服務/外幣/移轉訂價、員工/承攬/薪資、存貨、固定資產/資本化、多國、政府補助、虛擬資產、金融工具與股權交易，必須列入 CPA/記帳士/稅務/律師問題包。
